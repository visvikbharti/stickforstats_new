## What was fixed to get here

Four rounds, every number re-derived by execution. Full ledger:
[`BMC_SUBMISSION_VERIFICATION_2026-08-04.md`](BMC_SUBMISSION_VERIFICATION_2026-08-04.md).

**Guardian** — `similar_shapes` was declared in `test_requirements` with **no validator behind it**,
so a 100× spread difference, bimodality and normal-vs-exponential all returned confidence 1.000 with
the assumption listed as checked. Now implemented (KS on median-centred groups, Bonferroni across
pairs). A construction-time invariant, `_assert_every_requirement_is_implemented`, now refuses to
build a `GuardianCore` where any declared requirement lacks an implementation. The cascade engine
**failed open** — a Guardian *crash* was recorded as `guardian_passed=True`. Unknown test types and
uncheckable data now raise (HTTP 400) instead of returning clean reports. A chi-square without a
declared table no longer claims Cochran's rule was applied. Validators 8 → 9.

**Statistics** — log2 fold change was a ratio of means taken on data already log-scaled; Case Study 4
re-run (MKI67 +0.23 → **+0.97**; Group A/B separation 2.36× → **1.13×**). Multi-group analyses no
longer report `log2_fold_change = 0.0` *and* both group means as 0.0. The t-test now returns a CI and
Cohen's d, and **refuses** both on degenerate input rather than emitting a zero-width "95% CI". A NaN
from Levene no longer reads as a violated assumption nor 500s the endpoint.

**Manuscript** — reference 5 did not exist; the abstract's premise misread its only source; Fig. 7
printed Guardian's variance verdict inverted; Fig. 3 was a screenshot of a broken build; S1.5's
"0.2 ms" was a cache artifact. All corrected, all re-executed.

## The rules, updated

The four rules in [`README.md`](README.md) still hold. This arc added three:

5. **A label can lie — assert BEHAVIOUR.** Before the deploy, the live site listed `similar_shapes`
   in `assumptions_checked` precisely *because* nothing evaluated it. The label was evidence of the
   bug. Deploy verification now asserts what the software *does*: a 100× spread must raise a
   violation (0.444, not 1.000); the t-test must return `ci_lower`/`ci_upper`/`effect_size`; an
   unknown `test_type` must 400; anonymous access must still 401.
6. **A plausible-looking test proves nothing.** The first escaping test used `<test>`, which
   reportlab tolerates; the mutation survived. What actually breaks it is `<` followed by text and
   never closed — the real `P(X<Y)`. Mutation-check with data that reproduces the *actual* failure.
7. **Artifacts lie too — extract and grep them.** A 45 KB PDF with a valid `%PDF-` header turned out
   to be a rendered "file not found" page. The cover letter uploaded to the portal still said "eight
   validators" and "fewer than 20%" an hour before submission. Neither was visible by reading.

## What is genuinely open

Nothing blocking. Known and disclosed:

- The shape check is **conservative and underpowered at small n** — two lognormal groups differing
  threefold in spread are flagged in 0.5% of replicates at n = 12 vs 24, 67% at n = 40/group. Stated
  as a limitation in the manuscript.
- `modality` is implemented but reachable from no test type; `sample_size` only from factor analysis
  and PCA.
- MANOVA declares univariate assumptions only — multivariate normality and Box's *M* are not
  implemented, and every surface that renders the report says so.
- Wilcoxon signed-rank's actual assumption (symmetry of the differences) is not implemented; the
  requirement is dropped for paired designs rather than silently no-op'd.
- pytest has 21 pre-existing failures. **CI runs `manage.py test`, not pytest** — they are
  CI-invisible and cover dead code.
