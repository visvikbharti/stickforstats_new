## (b) Findings

### F1 — HIGH — CRISPR Case Study 1 headline statistics (F=1122.10, H=36.59) have NO checked-in replication path
**Category:** scientific_integrity
**Evidence:**
- `manuscript.md:191`: *"**Traditional approach (ANOVA):** F = 1122.10,
  p = 1.34e-35."*
- `manuscript.md:193`: *"Guardian cascaded to Kruskal-Wallis H test, which
  yielded H = 36.59, p = 5.62e-08 with eta-squared H = 0.93"*.
- `manuscript.md:18` (abstract) and `:182-189` (Table 6) state the modality
  means/SDs (ABE 0.587±0.024, etc.) to 3 decimals.
- `find` over the repo returns NO `case_study_1`/CRISPR replication script;
  `MASTER_VERIFICATION.py:26-32` lists only Iris/Wine, meta, additional, and
  Case Study 4 — **Case Study 1 is absent from the master verifier**.
- `MASTER_VERIFICATION.py:91-92` nevertheless prints *"Case Study 1 (Iris):
  Real data, verified results"* — i.e., the verifier's "Case Study 1" is
  Iris, NOT the CRISPR study in the manuscript; the manuscript's Case Study 1
  (CRISPR) is unverified by any script.
- `docs/CRISPR_GUARDIAN_DEMO.md` exists as a demo note for the CRISPR study.
**Doc claim:** Manuscript presents F=1122.10 / H=36.59 / Table 6 means as
concrete, reproducible results of Case Study 1.
**Reality:** No replication artifact in `paper/replication/` regenerates
these numbers. They derive from a CRISPRArchitect v3 run that is not
reproduced in the published replication package.
**Recommendation:** Add a `case_study_1_crispr.py` to `paper/replication/`
that regenerates Table 6 and the ANOVA/Kruskal-Wallis numbers from a
checked-in TOPSIS-score CSV (with a fixed seed if any randomness is
involved), wire it into `MASTER_VERIFICATION.py`, OR clearly label the
CRISPR numbers as illustrative tool output not part of the reproducible set.

### F2 — HIGH — Confidence formula in the manuscript is the non-production code path AND is mathematically degenerate (constant 0.1667)
**Category:** statistical_correctness / doc_mismatch
**Evidence:**
- `manuscript.md:85-89`: *"Each validator returns a severity level …
  weights w = 3.0, 2.0, 1.0 … The composite confidence score is:
  C = max(0, 1 - sum(w_i) / (W_max x 1.2))"*.
- This matches `guardian_core.py:627-648` `_calculate_confidence_v2`, whose
  own docstring (`:629-633`) states it is the *"Alternative confidence model
  (NOT wired into the main path) … `_calculate_confidence` above is what the
  API actually calls."*
- The production method `guardian_core.py:604-624` `_calculate_confidence`
  uses `max(0.0, 1.0 - total_penalty)` with severity penalties
  critical=0.25 / warning=0.10 / minor=0.03 — different formula, different
  weights, no `W_max·1.2` term.
- The v2 formula is degenerate: each iteration increments BOTH `max_penalty`
  and `total_weighted_score` by the same `w`, so they are always equal,
  giving `C = max(0, 1 - 1/1.2) = 0.1667` for any non-empty violation set.
  (Verified by reasoning over `:644-648`.)
- MEMORY.md repeats the wrong claim ("confirmed at guardian_core.py:662").
- The manuscript's own case-study confidence numbers are NOT produced by
  this formula: e.g. `manuscript.md:193` reports CRISPR "Confidence score =
  0.72", `:201` Wine "0.58", `:209` meta "0.42" — none equal 0.1667, so the
  printed formula cannot have generated the printed confidences.
**Doc claim:** Methods describes the v2 formula as THE Guardian confidence
score.
**Reality:** Production uses a different formula; the printed formula is dead
code that would output a constant.
**Recommendation:** Replace `manuscript.md:87` with the production
`_calculate_confidence` formula and weights; fix/delete
`_calculate_confidence_v2`; correct MEMORY.md.

### F3 — MEDIUM — IndependenceValidator mislabel and Anderson-Darling step-function p-values are described accurately in the paper but rest on known math caveats
**Category:** statistical_correctness
**Evidence:**
- `manuscript.md:66`: independence = *"Lag-1 Pearson autocorrelation on
  observation order … Distinct from the Durbin-Watson statistic [20]"*.
  This is an HONEST description (the paper explicitly disavows Durbin-Watson),
  and matches MEMORY's note that the validator computes lag-1 Pearson
  autocorr, not Durbin-Watson. Good: the paper does not overclaim here.
- However, MEMORY records the Anderson-Darling p-values are categorical
  step-functions (`guardian_core.py:710-714`) — the paper's Methods (`:64`)
  cites Anderson-Darling [17] without that caveat. Minor, since A-D is used
  only as confirmation for n>5000.
**Reality:** Paper's independence description is honest; A-D caveat omitted.
**Recommendation:** Add one sentence noting A-D p-values are reported at
standard significance thresholds (step function), not continuous.

   TOPSIS-score CSV + `case_study_1_crispr.py` regenerating Table 6, the
   ANOVA F=1122.10 and Kruskal-Wallis H=36.59, and wire it into
   `MASTER_VERIFICATION.py`; or relabel the numbers as non-reproducible tool
   output. (F1)
2. **(Blocker) Fix the confidence formula in the paper** to match the
   production `_calculate_confidence` (penalty-subtraction model, weights
   0.25/0.10/0.03), and fix/delete the degenerate `_calculate_confidence_v2`.
   Correct MEMORY.md. (F2)
3. **Make Case Study 4 offline-reproducible in CI** using the committed
   MD5-checked gz so review does not require a live GEO fetch. (F5)
4. **Regenerate and date-stamp** test counts and manuscript word/page stats
   in both manuscript and MEMORY. (F4, F6)
5. **Add the Anderson-Darling step-function caveat** to Methods. (F3)
6. **Optionally re-run S5 with DEBUG=False** for a production-representative
   latency. (F7)
7. Keep the anti-fabrication discipline (return-code verifier, R cross-check,
   honest independence/benchmark disclosures) — it is the manuscript's
   strongest asset. (F8)

**Overall verdict:** The manuscript is a complete draft with all six figures
and a complete reference list; three of four case studies (Iris, Wine,
meta-analysis) and Case Study 4 are backed by checked-in replication scripts,
and the meta-analysis is cross-validated against R. Two issues block a
clean submission: (F1) the CRISPR Case Study 1 headline numbers have no
reproducible path in the replication package, and (F2) the confidence
formula printed in Methods is dead, mathematically degenerate code rather
than the production formula. Both are fixable without new science. There is
no evidence of fabricated data in the script-backed case studies, and Case
Study 3 cherry-picking is confirmed remediated.
