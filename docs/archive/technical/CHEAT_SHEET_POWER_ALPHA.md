# Power & Alpha - 5-Minute Cheat Sheet

**Read this 5 minutes before your presentation**

---

## 🎯 CORE DEFINITIONS (Memorize These 4 Lines)

```
α (Alpha) = FALSE POSITIVE rate (usually 0.05 = 5%)
           "Risk of seeing an effect that isn't there"

Power = DETECTION rate (usually 0.80 = 80%)
        "Ability to spot a real effect"

Effect Size = HOW BIG the difference is (d = 0.2, 0.5, 0.8)
              "Small, medium, or large effect"

PowerCalculator = PLANNING tool (calculates n before study)
                  "How many subjects do I need?"
```

---

## 💬 3 QUICK ANSWERS (Pick One Based on Time)

### **10-Second Answer:**
> "PowerCalculator plans studies using parameters like alpha and power. No raw data to validate, just planning numbers."

### **30-Second Answer:**
> "PowerCalculator does sample size planning. You input significance level (alpha, usually 0.05), desired power (usually 0.80), and expected effect size. It calculates required sample size. These are abstract parameters for planning - there's no raw data for Guardian to check."

### **60-Second Answer:**
> "PowerCalculator performs statistical power analysis for study design. Researchers input alpha - their false positive tolerance, usually 0.05 - plus desired power - probability of detecting real effects, usually 0.80 - and expected effect size from pilot data or literature. The calculator determines required sample size. This is prospective planning before data collection, using abstract parameters, not measurements. Guardian validates distributional assumptions of raw data. PowerCalculator has no data - just planning parameters. You can't check if '0.05' is normally distributed; it's not a data point, it's a decision parameter."

---

## 🛡️ WHY NO GUARDIAN? (One-Line Answer)

> "Guardian checks data distributions. PowerCalculator uses planning parameters (α, power, effect size) - no data to check."

## 📊 ANALOGY (If They Look Confused)

## 🚨 IF THEY PUSH BACK

**Objection**: "But couldn't you validate the effect size?"

**Response**:
> "Effect sizes in PowerCalculator come from literature summaries or pilot studies - they're already-computed parameters (like d=0.5), not raw data. If from a pilot study, that original pilot data WAS Guardian-validated during analysis. But once you extract 'd=0.5' as a summary parameter for planning your next study, you're no longer working with raw data."
