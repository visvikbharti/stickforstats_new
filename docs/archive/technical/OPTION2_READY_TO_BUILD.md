### **STEP 2: Create Cards (60 minutes)**

#### **Option A: Template Method (Recommended)**

1. **Create Wansink card (first card):**
   - Card background: 75×110mm, #FFEBEE, 3pt red border
   - Icon: 🔴 (40pt)
   - Title: "WANSINK" (20pt bold)
   - Number: "17" (42pt bold, red)
   - Subtitle: "Papers Retracted" (16pt)
   - Description: "P-hacking via emails" (14pt)

2. **Group all elements:** Select all → Ctrl+G

3. **Duplicate 8 times:** Ctrl+D (8 times)

4. **Position in grid:** Use coordinates from CARD_CONTENT_QUICK_REFERENCE.txt
   ```
   Row 1: Wansink (15, 15), Stapel (102, 15), Psychology (189, 15)
   Row 2: Duke (15, 140), Wakefield (102, 140), Anversa (189, 140)
   Row 3: STAP (15, 265), Reinhart (102, 265), Guardian (189, 265)
   ```

5. **Ungroup each:** Select card → Ctrl+Shift+G

6. **Edit text:** Open CARD_CONTENT_QUICK_REFERENCE.txt
   - Copy text for each card
   - Paste into Inkscape
   - Apply colors (red for 1-8, green for 9)
