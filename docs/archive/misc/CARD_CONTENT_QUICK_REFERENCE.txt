================================================================================
CARD ELEMENT STRUCTURE
================================================================================

Each card contains 7 elements (from top to bottom):

1. Card Background (rounded rectangle, 75×110mm)
2. Icon (40pt emoji, 5mm from top)
3. Title (20pt bold, 5mm below icon)
4. Number (42pt bold, 5mm below title)
5. Subtitle (16pt semibold, 10mm below number)
6. Description (14pt, 5mm below subtitle, can be 2 lines)
7. Badge (rounded rectangle with text, 5mm below description)


================================================================================
QUICK CREATION STEPS
================================================================================

1. Create Wansink card completely (all 7 elements)
2. Select all elements → Group (Ctrl+G)
3. Duplicate 8 times (Ctrl+D repeatedly)
4. Arrange in 3×3 grid using positions above
5. Ungroup each card (Ctrl+Shift+G)
6. Replace text for each card (copy from this file)
7. Change colors for Guardian card (green instead of red)
8. Add section title at top
9. Add footer box at bottom
10. Align & polish
