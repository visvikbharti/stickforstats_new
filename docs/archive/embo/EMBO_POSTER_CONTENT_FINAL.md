### The Science Behind Guardian:

**Normality Testing Strategy:**
- Small samples (n<50): Shapiro-Wilk test (most powerful)
- Large samples (n≥50): Anderson-Darling (more stable)
- Visual: Q-Q plots with confidence bands
- Threshold: α = 0.05 (adjustable)

**Variance Homogeneity:**
- Levene's test (robust to non-normality)
- Brown-Forsythe variant for skewed data
- Automatic fallback to Welch's correction if violated

**Linearity Detection:**
- Ramsey RESET test for regression
- Polynomial term significance testing
- Curvature detection in residuals
