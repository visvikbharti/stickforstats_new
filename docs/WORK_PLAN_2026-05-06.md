### Statistical correctness (all done)
- [x] **P2.7** IndependenceValidator no longer claims Durbin-Watson → commit `afcf6bb`
  - Renamed `test_name` to "Lag-1 Autocorrelation (Pearson)"
  - Real p-value via `scipy.stats.pearsonr`'s t-distribution test
  - Combined practical (|r| > 0.3) AND statistical (p < alpha) gates so tiny |r| in n=10000 doesn't trip "violation"
  - Time-order assumption surfaced in message + recommendation
- [x] **P2.8** Anderson-Darling continuous p-value → commit `afcf6bb`
  - New shared helper `backend/core/utils/anderson_darling.py` with D'Agostino-Stephens 1986 closed-form
  - Replaces step-function categorical p in {0.15, 0.10, 0.05, 0.025, 0.01, 0.001} (and 2-valued for n>5000)
  - Used in both `guardian_core.NormalityValidator` and `services.assumption_service`
- [x] **P2.9** Wilcoxon r effect size → commit `a37ee71`
  - Now computed as `|Z| / sqrt(N)` (Rosenthal 1991) via the normal approximation
  - Was W / max(W) under misleading "r (effect size)" label
  - Z statistic also surfaced in `additional` dict
- [x] **P2.10** Kruskal-Wallis ε² label → commit `a37ee71`
  - Primary effect_size = unbiased eta-squared H = (H − k + 1) / (n − k), labeled "eta-squared H (unbiased; Tomczak & Tomczak 2014)"
  - Epsilon-squared = H / (n − 1) reported in `additional` dict for callers who want it
- [x] **P2.11** Genomics silent failure → commit `b1a28b4`
  - Mann-Whitney `(0.0, 1.0)` fallback replaced with `(NaN, NaN)` + `test_failed=True` + `test_failure_reason`
  - GeneResult.to_dict() converts NaN to None for JSON safety; reports `significant=False` without claiming a result
  - Normality + variance NaN-from-scipy now also forces cascade (was silently treated as "passed")
- [x] **P2.12** Critical except:pass swallows → commit `b1a28b4`
  - genomics: 4 sites now log + record violation + force cascade
  - cascade_engine `_execute_test`: `logger.exception` (with traceback) instead of `logger.error`
  - bayesian_correlation bare `except:` → `except (ValueError, RuntimeError, ArithmeticError)` with debug log
  - Other less-critical sites (parser.py, multivariate_service.py, billing_service.py, etc.) deferred to Phase 6 cleanup if time permits
