## DATA ANALYSIS PLAN

### Quantitative Analysis:

**Likert Scale Items (Q4-Q24, Q31)**:
- Calculate mean and standard deviation for each item
- Create summary table
- Identify highest-rated and lowest-rated features
- Group by participant experience level (beginner/intermediate/advanced)

**Net Promoter Score (Q32)**:
- Calculate NPS: (% Promoters 9-10) - (% Detractors 0-6)
- Target: NPS > 0 (acceptable), NPS > 30 (good), NPS > 50 (excellent)

**Comparison Questions (Q20-Q23)**:
- Frequency count for each comparison
- Calculate % who rated platform as "better" or "much better"
- Cross-tabulate with user role (student vs professional)

**Completion Metrics (Q1-Q3)**:
- % who completed all lessons
- Common barriers to completion
- Correlation with satisfaction

### Qualitative Analysis:

**Thematic Coding (Q25-Q30, Q39)**:
- Read all responses
- Identify recurring themes
- Code responses by theme (positive, negative, neutral)
- Count frequency of each theme
- Select representative quotes for publication

**Expected Themes**:

- Negative: Formula rendering issues, wanted more practice, navigation confusion
- Suggestions: More examples, mobile support, search function, practice problems
